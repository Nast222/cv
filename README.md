# Random Task Generator

## Автор: Яковлева

## Описание

Приложение с графическим интерфейсом для генерации случайных задач. Позволяет:
- Генерировать задачи из предопределённого списка.
- Добавлять собственные задачи.
- Фильтровать историю по типу (учёба, спорт, работа).
- Сохранять и загружать историю в файл JSON.
- Использовать систему контроля версий Git.

## Пример использования

1. Запустите `main.py`.
2. Нажмите «Сгенерировать задачу» — случайная задача появится в истории.
3. Введите свою задачу и выберите тип, затем нажмите «Добавить свою задачу».
4. Используйте фильтр для просмотра задач только определённого типа.
5. История сохраняется автоматически.
